Do chatbots escalate when someone describes suicidal thoughts?

Sareena Parikh

A re-evaluation of how Claude 3.5 Sonnet, GPT-4o, LLaMA and Mistral responded to 1,280 single-turn prompts from the MentalChat16K dataset. All 1,280 prompts were re-labeled, along with 300 responses covering every high-risk prompt.

Responses that gave crisis resources when the user described suicidal or self-harm thoughts. I re-labeled all 1,280 prompts in the dataset, and only these 11 contained explicit suicidal or self-harm thoughts. Another 17 expressed a passive wish. Both groups, plus mild stress, are compared in the Results tab.

Original study

  • Input severity came from keyword matching. A prompt mentioning "death" counted as imminent risk.
  • Output severity came from a separate ChatGPT session for each model.
  • Each response got one subjective 0 to 5 score.

Re-evaluation

  • One classifier with one fixed prompt, temperature 0 and structured JSON output.
  • It answers factual yes or no questions instead of giving a score.
  • A fixed rule turns the answers into the paper's severity levels.

Pipeline

  1. Combine

    1,280 prompts and 4 models in one table of 5,120 responses. It reproduces the paper's original figures.

  2. Ask questions

    gpt-4o-mini answers yes or no questions about each prompt and each response.

  3. Apply rules

    The highest level whose condition is met becomes the label. Every label can be traced to its answers.

  4. Validate

    Keyword cross-check, hand review and significance tests.

      What held up

      • Every model responds more strongly to explicit thoughts than to passive wishes.
      • Claude separates the groups most cleanly. It rarely gives crisis resources for mild stress and always does for explicit thoughts.
      • GPT-4o and LLaMA miss about half of explicit cases. Two of GPT-4o's five misses are a two-sentence template with no resources.
      • The original finding that responses ignore severity came mostly from the keyword input labels.

      Limits

      • The groups are small. 11 explicit and 17 passive prompts are enough for these gaps but not for precise rates.
      • No prompt in the dataset states active intent or a plan. Crisis handling at that level is untested here.
      • Mild-stress rates include conditional safety nets. The classifier does not yet separate them from direct crisis responses.
      • These are API responses with no system prompt. Consumer apps may add their own safeguards.
      • The input questions were refined on the same 26 prompts used in the hand review. A fresh hand-labeled sample is the next test.
